# Textersetzungen

Dieses Dokument beschreibt die Einbindung benutzerdefinierter Texte in die Anwendung und
listet alle erlaubten Key-Value-Paare auf. Die Key-Value-Paare können im Feld: `<CustomTexts>` in der **Testtaker-XML** hinterlegt werden.

```
<CustomTexts>
    <CustomText key="login_testEndButtonText">Test beenden</CustomText>
    <CustomText key="login_bookletSelectPrompt">Bitte wählen</CustomText>
</CustomTexts>
```

::: tip Hinweis
Detaillierte Informationen zur Testtaker-XML finden Sie [hier](https://iqb-berlin.github.io/tba-info/study-run/preparation/test-files/testtaker-xml.html).
:::

::: tip Hinweis
Textersetzungen für den **Systemcheck** werden im Feld: `<Config>` in der **Systemcheck-XML** angegeben.
:::

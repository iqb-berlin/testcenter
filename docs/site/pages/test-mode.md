# Studien Test-Modus

Die Auswahl eines Test-Modus erfolgt im Feld `<Login>` mit dem Attribut `mode` in der **Testtaker-XML**.

```
<Login mode="run-hot-return" name="test" pw="user123">
  <Booklet>BOOKLET.SAMPLE-1</Booklet>
</Login>
```

Das Testcenter ermöglicht die Durchführung des Tests in verschiedenen Modi.
Für jede Anmeldung wird ein Modus festgelegt. Jeder Modus verfügt über spezifische Eigenschaften. Nachfolgend sind diese Eigenschaften aufgeführt.

::: tip Hinweis
Detaillierte Informationen zur Testtaker-XML finden Sie [hier](https://iqb-berlin.github.io/tba-info/study-run/preparation/test-files/testtaker-xml.html).
:::

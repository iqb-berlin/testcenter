# Testheft Konfiguration

Dieses Dokument beschreibt die Konfiguration des Testheftes im Feld: `<BookletConfig>` in der **Booklet-XML**.
Hier können die nachfolgend aufgelisteten Key-Value-Paare hinterlegt werden.

```
<BookletConfig>
    <Config key="force_responses_complete">OFF</Config>
    <Config key="unit_navibuttons">LABEL</Config>
</BookletConfig>
```

::: tip Hinweis
Detaillierte Informationen zur Booklet-XML finden Sie [hier](https://iqb-berlin.github.io/tba-info/study-run/preparation/test-files/booklet-xml.html).
:::
